# Goot — Development Plan

| Phase | Scope | Status | Verification Notes |
| :--- | :--- | :--- | :--- |
| **Phase 1: Compiler Verification** | Read official Goose documentation ([tutorial](https://aardappel.github.io/goose/docs/tutorial.html), [reference](https://github.com/aardappel/goose/blob/master/docs/reference.md), [packages](https://aardappel.github.io/goose/docs/packages.html)), verify syntax, `root struct`, `extern fn`, and `.build` sidecar rules. | Complete (docs verified); `goose` binary absent in sandbox | Syntax verified against official Nov 2026 Goose docs; `goose check`/`goose build` must be run on target Artix host. |
| **Phase 2: Native Wayland** | `libwayland-client`, `xdg-shell` toplevel, `wl_shm` double buffering, HiDPI scale, frame callbacks, `wl_seat` keyboard/pointer, `wl_data_device` clipboard (`native/goot_wayland.c`, `native/goot_xkb.c`). | Source Complete | Requires `wayland-client`, `wayland-protocols`, `wayland-scanner`, `xkbcommon` on target host. |
| **Phase 3: PTY Integration** | Linux POSIX PTY (`posix_openpt`, `fork`, `setsid`, `TIOCSCTTY`, `TIOCSWINSZ`, `SIGCHLD` reaping) + `epoll`/`signalfd` event loop (`native/goot_pty.c`, `native/goot_poll.c`). | **Complete & Verified** | Compiled with `gcc -O2 -Wall -Wextra -Werror -std=c99` and passed `tests/test_native_pty_poll.c` (1 ms round-trip). |
| **Phase 4: Terminal Parser & Screen** | Streaming UTF-8, wide/combining chars, VT100/VT220/ECMA-48 CSI/OSC/SGR parser, screen grid, alternate buffer, bounded scrollback ring buffer (`src/utf8.goose`, `src/colors.goose`, `src/screen.goose`, `src/parser.goose`). | Source Complete | Unit tests authored in `tests/test_goot.goose`; requires `goose` compiler on target host to execute. |
| **Phase 5: Software Renderer** | Pixman software compositing, FreeType2 + Fontconfig + HarfBuzz glyph cache, per-row damage tracking (`native/goot_font.c`, `native/goot_render.c`, `src/renderer.goose`). | Source Complete | Requires `pixman-1`, `freetype2`, `fontconfig`, `harfbuzz` dev headers on target host. |
| **Phase 6: Interaction & Config** | Keyboard translation, shortcuts, mouse selection, SGR/X10 mouse reporting, Wayland clipboard paste sanitization, TOML/INI config parser (`src/input.goose`, `src/config.goose`, `goot.goose`). | Source Complete | Ready for `goose build` on target Artix Linux host. |
| **Phase 7: Compatibility** | Interactive testing with Bash, Fish, Zsh, Vim, Neovim, Nano, Htop, Btop, Less, Tmux, Fastfetch, OpenCode, Claude Code. | Pending Target Host | Cannot execute GUI Wayland terminal sessions in headless sandbox without `goose` and Wayland compositor. |
| **Phase 8: Optimization** | Profile hot paths (`goose check --stats`, `--bce-lines`, `perf`) and tune CPU/RAM/latency. | Pending Target Host | Architecture already uses event-driven `epoll`, batched PTY reads, bounded glyph cache, and row-level damage. |
| **Phase 9: Final Validation** | Full build, test execution, benchmark comparison against Foot/Kitty/Alacritty, and ZIP packaging. | Packaged as `goot.zip` | Native PTY/epoll verified in sandbox; full Wayland/Goose build & benchmarks ready to run on Artix Linux via `scripts/build.sh` and `benchmarks/run_benchmarks.sh`. |
